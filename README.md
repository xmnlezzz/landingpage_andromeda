# Andrómeda 4 — Landing page

Landing page estática lista para GitHub Pages.

## Publicación rápida

1. Sube todos los archivos de esta carpeta a un repositorio.
2. En GitHub abre **Settings → Pages**.
3. En **Build and deployment**, selecciona **Deploy from a branch**, elige `main` y `/ (root)`.
4. Guarda y abre la URL que GitHub genere.

El sonido se activa con el botón **ACTIVAR AUDIO**, ya que los navegadores impiden reproducir audio automáticamente sin interacción. La cuenta regresiva apunta al 30 de noviembre de 2026 a las 23:59:59, hora de Sinaloa.
